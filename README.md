# ПЯТЫЙ ЭТАЖ

Психологический хоррор от первого лица по концепту: панельная пятиэтажка, май 2000 года,
квартира 47, пять ночей, монстра нельзя убить — можно только не открывать, не смотреть и не отвечать.

> «В этом доме нет шестого этажа. Но ночью ты слышишь, как над тобой ходят.»

## Скачать готовый .exe (Windows)

**[Скачать PyatyyEtazh.exe](https://github.com/gggvkvh405-rgb/GameByAzen/releases/download/v1.0.0/PyatyyEtazh.exe)** (страница релиза: [Releases](https://github.com/gggvkvh405-rgb/GameByAzen/releases/tag/v1.0.0))

Portable: установка не нужна, просто запусти файл. Windows SmartScreen может предупредить,
что файл без цифровой подписи, — «Подробнее» → «Выполнить в любом случае». F11 — полный экран.

EXE собирается автоматически GitHub Actions (Windows) из этого репозитория: `.github/workflows/build-exe.yml`.

## Как запустить на компьютере

Нужен только Node.js 18+:

```bash
npm install
npm run dev
```

Открой адрес, который покажет терминал (обычно http://localhost:5173).

Собрать статическую версию (папка `dist`, её можно открыть любым локальным сервером / залить на хостинг):

```bash
npm run build
npm run preview
```

## Что внутри

- Полностью играбельная кампания: пролог днём + 5 ночей + финал на шестом этаже
- Подъезд на 5 этажей (квартиры 37–56), квартира 47 с гостиной/спальней/кухней/ванной,
  квартира тёти Люды (43), квартира дяди Коли (38), подвал с котельной, чердак/шестой этаж
- Сущности со своими правилами: Стоящий (движется, только когда не смотришь), Хозяйка
  (стучит и просит открыть голосами соседки и бабушки), Двойник, Плачущий за стеной,
  Жилец Шестого Этажа
- Механики концепта: дверь и глазок (правило 3 секунд), затаить дыхание и слушать (Ctrl),
  дисковый телефон = сохранение, VHS-камера (видит лишнее), телевизор от шагов сверху,
  фонарь и лампочки, домовая книга и изменяющиеся Правила дома, рисунки Ани (5 шт.)
- Записанная озвучка: бабушка и тётя Люда за дверью, мама по телефону (с телефонным
  фильтром), счёт дверей, прогноз погоды по телевизору, хор подъезда по домофону,
  свой голос в трубке и Жилец Шестого Этажа. M — выключить/включить голоса
- Рассудок вместо здоровья, синтезированный звук (стуки, звонки, статика, шаги — WebAudio,
  файлов не нужно), русская озвучка стуков через SpeechSynthesis, если браузер умеет
- 4 концовки: «Уехал», «Старший по подъезду», «Шестой этаж» и секретный «Снос»
  (нужны все рисунки Ани и ни одной открытой чужой двери / нарушения глазка)
- PS1-настроение, современная картинка: рендер 720p, мягкие тени от фонаря, ACES-тонемаппинг,
  bloom и плёночный шум (three.js post-processing), PBR-текстуры 512px с потёками, трещинами
  и облупившейся краской, детальные модели мебели и персонажей, пыль в луче фонаря.
  В углу кадра по-прежнему дата VHS-камеры.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / мышь | движение / осмотр |
| E | действие (дверь, телефон, предметы) |
| F | фонарь |
| Q (у своей двери изнутри) | смотреть в глазок |
| Ctrl (держать) | затаить дыхание и слушать дом |
| Shift | бег (шум привлекает Стоящего) |
| V | VHS-камера (когда найдёшь) |
| Tab | домовая книга и правила |
| Esc | пауза |

Сохранение — только по телефону маме в квартире 47 (и автосейв при смене этапа в localStorage).

## Правила дома

1. После 23:00 не смотреть в глазок дольше трёх секунд.
2. Если стучат и молчат — это не к тебе. Не спрашивай «кто».
3. Если над тобой ходят после 03:33 — сразу включай телевизор.
4. Тёте Люде дверь не открывать. Тётя Люда умерла.
5. Себе дверь не открывать.
6. Чердак должен быть заперт. Всегда.

Если сегодня ночью над тобой будут ходить — включи телевизор.
